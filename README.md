# Gita Life Coach AI — Frontend-only starter

A mobile-first Next.js website prototype for exploring Bhagavad Gita wisdom.

## Included
- Responsive landing page
- Daily verse cards with 3 sample verse entries
- Ask Gita AI interface using local demo responses (NOT a live AI connection)
- Language toggle (interface labels and hero copy; sample verse explanations are mostly English)
- Bookmark state and journal stored in the current browser using localStorage
- No backend, database, login, API keys, or server-side AI calls

## Run locally
Install Node.js 18.17+ and npm, then from this folder:

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build static files
```bash
npm run build
```
The project is configured with Next.js static export (`out/` output). Some hosting providers may require configuration adjustments.

## Important
- AI answers are prewritten demo text and are not generated by an AI model.
- Browser localStorage is not cloud sync or secure storage for sensitive information.
- Verify Sanskrit text, translations, and interpretations against trusted editions before public launch.
- Ensure any image you use in production is licensed for your intended use. Replace the demo image URL with a properly licensed asset if needed.
- There is no backend by design. To add real AI, authentication, or synced storage later, a secure server/API and appropriate provider setup will be required.
